# Campus Club Management System

## Project Description
A web-based application for managing campus clubs.

## Technologies Used
- Node.js
- Express.js
- SQLite
- HTML
- CSS
- JavaScript

## Features
- View all campus clubs
- View individual club details
- Add a new club
- Update club information
- Delete a club

## Running the Project Locally
1. Install Node.js.
2. Open a terminal in the backend folder.
3. Run `npm install`.
4. Run `node server.js`.
5. Open the frontend application as configured in the project.

## API Endpoints
- GET `/api/clubs`
- GET `/api/clubs/:id`
- POST `/api/clubs`
- PUT `/api/clubs/:id`
- DELETE `/api/clubs/:id`
